This Python script allows users to fetch and display the current weather report for a specified city using the wttr.in web service. To use the script, simply input the city name when prompted, and the script will fetch and print the weather details for that location. It utilizes the `requests` library to make an HTTP GET request to the wttr.in service. To get started, ensure you have Python installed, clone the repository, and run the script. The script will prompt you to enter a city name and then display the weather report for that city.
